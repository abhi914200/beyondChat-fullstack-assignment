# BeyondChats – Full Stack Web Developer Assignment

## Overview
This project is a multi-phase full stack assignment for the BeyondChats Full Stack Web Developer Intern role.  
It involves web scraping, API development, content transformation using LLMs, and a React-based frontend.

## Tech Stack
- Backend: Node.js, Express.js, MongoDB
- Frontend: React (Vite)
- Scraping: Axios, Cheerio
- AI: LLM API (Phase 2)

## Project Phases
1. Scrape and store articles + CRUD APIs
2. Content enhancement using Google Search + LLM
3. React frontend to display articles
